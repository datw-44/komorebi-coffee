## 確認

同じ公開コミットの修正前画像と、修正版のローカルHTTP表示を比較。両幅で画像5点の読み込みとページ横幅を確認。ページ内アンカーの参照先はすべて存在し、スマホナビの開閉・ABOUTへの移動・Escと、ABOUTからメニューへの移動を確認。ブラウザコンソールにエラーなし。写真・価格・営業時間・配色と主要レイアウトは既存版を使用。情報行と紹介文を削ったことで、INFORMATIONの高さは短くなる。

画面幅はviewport指定。スクロールバーにより画像実寸が指定値より小さい。実機では未確認。
